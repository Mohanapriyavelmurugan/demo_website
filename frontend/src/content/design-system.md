# Valtraq visual system — Option A (Premium clinical vitality)

## Direction
- Light mode, healthcare-trustworthy, impressive craft
- No AI purple, neon, carousels, or scroll-jacking
- Motion purposeful; respect `prefers-reduced-motion`

## Palette
- Paper background: warm ivory
- Ink: near-black navy for headlines
- Living teal: primary interactive + deep band
- Champagne gold: eyebrows, status pills, accents
- Section grounds: `paper` / `mist` / `sand` / `band` / `hero`

## Type
- Display: Fraunces
- Body: Source Sans 3 (16px+)

## Motion kit
- `Reveal` variants: up, left, right, scale, blur
- `StaggerChildren` / `StaggerItem`
- `AnimatedHeadline` (short headlines only)
- `HoverLift`
